<Update label="v0.10.0-rc" description="New navigation, search, and work item graphs">
  ## What's new in v0.10.0-rc?

  This is our biggest release yet. Every app now has its own dedicated navigation, search has been rebuilt from the ground up, work items gained a whole new way to visualize their connections, and projects can now be explored as a mind map. We also renamed Tasks to Work Items across the entire product.

  ### ✨ New features & improvements
  * **New navigation:** Every app — Docs, Projects, Registry, Time Tracking, and more — now opens in its own dedicated sidebar, reached through a compact icon rail. Switching between apps is faster, and each app has more room for its own navigation.
  * **Tasks are now Work Items:** We renamed Tasks to Work Items across menus, settings, permission categories, and reports, to better reflect everything you track: stories, bugs, subtasks, and more.
  * **Relation Graph for work items:** Open any work item and switch to the new Relation Graph to see how it connects to other work items, pages, test cases, and registry objects at a glance.
  * **Project Mind Map:** Projects now have a Mind Map view that lays out your work item hierarchy visually. Expand any branch to reveal its subtasks and jump straight into any item.
  * **Rebuilt search:** Search has a new interface with instant results, recent searches, and smarter filters, making it faster to find pages, work items, and registry objects.
  * **Registry relation graph:** Registry objects also gained a visual relation graph, showing how connected objects link together across multiple levels.
  * **Work items linked to pages:** You can now link a wiki page directly to one or more work items, and see those links from the page itself.
  * **Requirement Coverage reports:** Test Management adds a Requirement Coverage report, showing which requirements are fully tested, partially tested, or not covered yet.
  * **Quicker profile access:** Profile and Preferences now open in a quick popup from anywhere, instead of a separate settings page.

  ### 🎨 Layout & UX
  * **System settings & permissions:** Settings pages and permission categories were reorganized and relabeled to match the new Work Item terminology, making it easier to find the right setting.
  * **Registry object history:** Registry objects now show a detailed activity history of every field change, and object types use a clearer, more consistent icon set.

  ### 🛠 Stability & Maintenance
  * **GitHub integration reliability:** Fixed an issue where linking a repository to a project did not always save correctly, and resolved conflicts that could occur when multiple spaces each connect their own GitHub repository.
  * **Performance:** General performance and reliability improvements across both the self-hosted and cloud versions of Collabase, including faster page loads and more efficient background processing.

  ### 🔒 Security & Vulnerabilities
  * Closed several access-control gaps in the GitHub integration that could, in specific configurations, expose repository link data to users outside the intended space.
  * Fixed a session-handling issue in the GitHub app connection flow.
</Update>
