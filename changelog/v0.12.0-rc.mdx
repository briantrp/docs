<Update label="v0.12.0-rc" description="Estimates at creation, cycle-aware sub-items, search & editing fixes">
  ## What's new in v0.12.0-rc?

  This release makes planning quicker: you can estimate a work item as you create it, sub-items now stay in step with their parent's cycle, and a few rough edges in editing and search are gone.

  ### ✨ New features & improvements
  * **Estimate while creating a work item:** The create dialog now has an estimate field. Depending on how the project estimates — story points, T-shirt sizes, or hours — you can set the value right away instead of opening the work item afterwards. The field only appears when estimation is turned on for the project.
  * **Sub-items stay with their parent's cycle:** When you add a sub-item to a work item that is already in a cycle, it now follows the parent into that cycle automatically — provided the project's **Carry child work items** cycle setting is on. If that setting is off, a small prompt appears offering to add the new sub-item to the cycle, so nothing lands in the wrong place by accident. Both behaviours are only available to members who may manage cycle scope.

  ### 🎨 Layout & UX
  * **Steadier title editing:** Editing a work item's title no longer shrinks the text while you type — the title keeps its size and gains a subtle outline to show it is editable.
  * **Backlog stays put:** Changing an estimate on the last item in the backlog no longer scrolls the list back to the top.

  ### 🛠 Stability & Maintenance
  * **Cleaner search after deleting:** Deleted work items, pages, and folders no longer show up in search results or in the "recently viewed" suggestions.
</Update>
